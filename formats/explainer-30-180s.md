# 片型：功能讲解（30–180 秒）

让观众理解并能复述一次真实操作。配音 + 字幕为默认，用户明确要纯字幕时按阅读时长组织。不是把宣传片加一条旁白。

## 制作顺序

1. 选一个问题、目标结果与必要前提，列出 3–5 个操作步骤。每步绑定真实 UI 状态和可验证结果；模拟过程单独标识。
2. 写逐句讲稿、字幕与屏幕动作三列表。以“说到什么，画面就展示什么”为准，术语与产品一致，不一边讲下一步一边展示上一步。
3. 用实际录音 / 生成的已授权配音测时间，再安排操作和阅读停顿；草稿可以估时，但不能把估时当最终对齐。配音来源、使用许可与音色记入素材表。
4. 不强制音乐先于旁白定轴。配乐可选，先保证人声、操作因果和字幕阅读；不能为吸拍加速输入、跳过必要结果或改变产品响应速度。
5. 确认点 1 一次提交方向静帧、分镜、讲稿及声音方案；沿用两确认点，不额外逐项审批。

## 镜头与字幕

- 2D 正视 UI 承担步骤，空间段可解释整体关系或展示结果，但不替代可读操作。
- 一镜一项操作目的，5–10 秒一段只作起点；复杂步骤按实际时长拆镜，而不是缩小字幕。
- 字幕按语义断句，默认最多两行；出现、消失按实际音频对齐，留足读完时间。检查逐字稿、专有名词、数字和关键否定词。
- 不用字幕遮住点击目标、菜单、结果或平台 UI。烧录字幕与 SRT / VTT 文件按交付约定提供，不擅自更换交付类型。
- 处理等待可明确加速或省略，但不能把模拟结果当实际成功，也不能暗示未验证的响应性能。

## 专属检查

- [ ] 先讲用途与结果，再给步骤，观众能复述如何操作
- [ ] 每句旁白、字幕与 UI 状态对应；没有未解释的跳步
- [ ] 用实际音频逐句核过同步，人声清晰、不被音乐盖住
- [ ] 静音播放仍能靠字幕与画面理解，真实投放尺寸下读得完
- [ ] 数字、等待压缩、演示状态与实际能力边界明确
- [ ] 结尾按用途给下一步 / 结果总结，时长符合约定，不强制宣传片式 CTA 落版
