# 片型：首屏循环（6–15 秒）

无声、可反复播放，只讲一个核心关系或能力。首帧就要成立；品牌可来自页面周边或画面内，不强塞宣传片的 hook → 多能力 → CTA 全流程。

## 分镜与画面

- 确认承载页面、显示尺寸、背景、播放行为与海报帧；容器裁切和文字层归属写入分镜。
- 选一个可闭环的母题：真实输入到结果再回到准备态、成果连续排列、空间展示回正视 UI。闭环不能伪造用户实际工作流；抽象展示与真实操作分开。
- 允许丰富的材质、密度变化与必要 3D，但每轮只保留一个主信息；细字阅读仍需正视停留。
- 默认无独立落版、3–4 秒 CTA 停留、片尾淡黑或配乐；页面已有 CTA 时不在视频重复。

## 接缝与时间

- 定义周期 T，画面状态满足 t=0 与 t=T 一致；有连续运动时还要匹配接缝两侧的速度 / 方向，不能只对齐两张静帧。
- 导出帧范围为 `[0,N)`，N=T×fps；不额外重复 t=T 的端点帧，避免循环顿一帧。时长选择应能对应整数帧数。
- 检查最后几帧接第一批帧的正常播放，连播至少三轮；不能只拿首尾图片像素相等就判通过。
- 有意停顿可放在闭环处，但不要为了接缝掩盖跳变而机械加黑场。

## 专属检查

- [ ] 首帧、海报帧和页面容器一致，未加载 / 不播放时仍有有效信息
- [ ] 无声下能理解一个核心能力或关系，不依赖旁白
- [ ] 实际页面显示尺寸下文字、结果和主体清楚
- [ ] 接缝状态、相机、纹理、光照和内容连续；运动没有突然减速 / 反向
- [ ] 三轮连续播放无闪黑、重复端点卡顿或无目的空等
- [ ] 没有误套宣传片落版、淡黑或配乐规则
