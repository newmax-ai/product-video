# 片型：社交竖屏短片（15–30 秒）

以 9:16 为起点，在第一秒给出具体结果、问题或正在发生的能力；只讲 1–2 条主张，不把横版宣传片裁成竖条。仅在本片实际制作目标是竖屏短片时采用，不由参考视频所在平台推定。

## 分镜与安全区

- 确认目标平台、发布版位、预期显示尺寸、是否有字幕 / 配音，以及封面和 CTA。平台遮挡会变化，按本次真实预览或当前版位规范取值，不沿用固定“上 85%”。
- 在分镜标出顶部、底部、左右互动区的遮挡范围；无法核实时注明假设，先做保守布局，不声称已通过平台验收。
- 建议节奏：立即给结果 / 问题 → 一次核心操作与证据 → 结果读稳 → 简短下一步。具体秒数按阅读与音乐调整。
- 竖屏重新组织上下关系和主体比例，不只缩小整窗。镜头可使用 2D、层次与真实 3D，但细字阅读回正视 UI。
- 标题、字幕、结果与 CTA 分工，避免四层文字同时争夺视线；结尾停留按信息量与约定，不机械套 3–4 秒。

## 专属检查

- [ ] 第一秒已有明确内容，不把空 logo 动画当开场
- [ ] 每条主张有真实证据，没有为了短时长伪造瞬时完成
- [ ] 按真实投放尺寸看过，28px 只是字号起点，不能代替手机阅读检查
- [ ] 目标版位的标题、头像、互动按钮、字幕等遮挡已核对；未知项明确记录
- [ ] 静音仍能理解，配音和字幕存在时逐句同步
- [ ] 封面可独立理解，裁切预览不遮住品牌和主信息
- [ ] 总时长、画幅与平台交付约定一致，不能拿横版检查代替竖版验收
- [ ] 参考与实际复用分开登记，素材 / 代码各自核权，未照搬第三方分镜或视频工程
