# 片型：发布会长片（90–180 秒）

一次讲多个新功能的版本发布片。长片需要清晰的章节关系与节奏变化，但不强制某一种导航组件。`references/case-studies.md` 的 Manus 案例提供一种组织方法，不是所有发布片的模板。

## 叙事骨架（按内容选择）

| 段 | 作用 | 120s 示例 | 可选表达 |
|----|------|-----------|----------|
| 开场 | 宣告更新及核心价值 | 0–6 | 直接能力现场、版本亮相或问题 |
| 章节 ×3–5 | 每章一个大主题，有操作与成果 | 6–96 | 章节标题、进度标记、目录滚轮或空间母题 |
| 重点收束 | 最重要成果或真正的新惊喜 | 96–110 | 代表作、完整工作流；有独立新能力时才用 One More Thing |
| 品牌落版 | 为什么做、下一步是什么 | 110–120 | 品牌主张、成果回扣、logo；按投放需要加 CTA |

时间只作预算起点；固定档期以用户约定为准。没有额外惊喜就把时间给核心能力，不为了模板把前文功能重复包装。主题超过 5 个时优先合并，章节数服从真实内容。

## 章节内部节奏

章节定位 → UI 输入 / 过程 / 结果 → 代表性真实产出 → 小结或下一主题。

- 定位可以由标题、声音、进度、构图或材质变化完成；目录滚轮是可选项，使用时保证高亮与顺序正确。
- 章内 3–4 秒一切可作起点，复杂操作与成果按阅读量停留，不强迫持续运动或每个动作吸拍。
- 同一章组合 UI、全屏结果、对照、空间关系等镜头，变化需支持叙事，不为凑镜头类型打断因果。
- 在确认点 1 一并选择美术方向与代表静帧。按需要穿插 2D 操作、2.5D 分层和真实 3D 亮相 / 成果展示；细字阅读回到正视 UI。
- 原地改写标题、深浅章节对比、手绘圈注均可使用，但不能复制参考片的固定次数和顺序。保留词须稳定，装饰不能压字。

## 收尾选择

- 发布现场可只用品牌落版；投放或获客场景给明确 CTA 和足够阅读时间。
- 可以用价值主张或代表成果收束，也可做简洁回顾；不默认必须“价值观 + 手绘圈注”。
- 若使用 One More Thing，必须是真正未出现的新内容，且有真实能力证据；不用时无需补空段。
- 标题短而可读，中文约 12 字可作起点。长片的理解依赖章节关系，不靠一屏塞满信息。

## 专属检查

- [ ] 只看章节标题与首句就能理解本次更新的结构
- [ ] 每章有真实 UI / 结果；模拟状态、品牌主张与实证明确区分
- [ ] 已选导航在换章时准确，且不抢占阅读时间；没选目录滚轮不视为缺项
- [ ] 有声与静音正常速度观看过，章节动静、构图和密度有变化
- [ ] 空间镜头检查体积、材质、相机目的与回 UI 衔接
- [ ] 若使用标题原地改写，保留词不跳动；若使用惊喜章节，内容确实独立
- [ ] 收尾与播放场景一致，时长符合已确认约定
