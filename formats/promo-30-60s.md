# 片型：宣传片（30–60 秒）

**默认没有旁白，文字承担解说；音乐支持节奏；能力镜头 = 一句短标题 + 真实视觉证据。** 用真实 UI、作品、排版与按目的选用的 2D / 2.5D / 3D 展示讲清产品。品牌与空间镜头建立视觉记忆，但不替代功能证明。

对应案例：`references/case-studies.md` 的 A ListenHub（30s）、B 小互（42s）、C YouMind（45s）；结合 `references/creative-direction.md` 制定自己的方向，不复制参考外壳。

## 六段骨架与时长分配

以下是预算起点；可选入口占用前一段或合并到结尾，不把重叠时间累加。结尾需要完整读稳 ≥3 秒，30 秒版本也要预留。

| 段 | 作用 | 30s 版 | 45s 版 | 60s 版 | 常用镜头（scene-library.md） |
|----|------|--------|--------|--------|-----------------------------|
| ① Hook | 3 秒内吸引并有内容 | 0–4 | 0–5 | 0–5 | H1 能力现场 / H2 信息潮水 / H3 问题 |
| ② 品牌亮相 | 这是谁、是什么 | 4–7 | 5–9 | 5–10 | B1 / B2，或有意义的 G1 主体亮相 |
| ③ 核心能力 ×3–4 | 一句能力 + 一个证据 | 7–20 | 9–30 | 10–40 | F1–F13；必要时 G2 分层并接 G4 回 UI |
| ④ 成果 / 信任 | 看质量与真实使用证据 | 20–27 | 30–40 | 40–52 | S1 / G3 成果展、S3 有来源数字、S4 真实证言 |
| ⑤ 延伸入口（可选） | 开发者、多端或渠道 | 并入 ④ / ⑥ | 38–40（从 ④ 腾出） | 50–54（从 ④ 腾出） | E1 / E2 / F13 |
| ⑥ 结尾 CTA | 名字 + 定位 + 行动 | 27–30 | 40–45 | 54–60 | End Card，呼应视觉母题 |

没有规模数字或证言时，用真实成果展示质量，不把作品墙写成“很多人正在用”。原则卡 S5 可以表达品牌主张，但不是信任证据，不替代缺失的功能实证。

## 叙事线三选一

- **能力直给型**（ListenHub）：hook 就是产品工作，再连续输入 → 结果；适合效果一眼可见的工具。
- **问题 → 方案型**（小互）：真实痛点 → 我替你解决什么 → 流程与证据；适合筛选、分析与内容工具。
- **情绪 → 动词型**（YouMind）：问题 → 品牌定位 → 三个动词串工作流；适合创作、学习、效率平台。

## 美术与维度策略

确认点 1 同时提交 2–3 个美术方向、代表静帧和分镜。差异应体现母题、构图、疏密、空间、材质光影与镜头，不是三个配色版本；不新增确认关。

- 2D 承担核心操作、细字、对照与 CTA。
- 2.5D 为轻视差或界面分层服务。
- 真实 3D 为主体亮相、成果空间关系或几何 / 光照服务；按镜头必要性安排，不全片 3D、不仅旋转卡片。空间配方 G1–G4 与工程入口 `references/three-workflow.md` 配合。
- 空间镜头之后回正视真实 UI，细节读得清，状态连续。丰富度来自主次、材质和疏密变化，不是让每帧都拥挤或一直动。

## 专属规则

1. **文字是解说**：默认不配音；标题连读成完整表达。一屏一句，通常中文 ≤12 字 / 英文 ≤7 词，说明 ≤25 字。产品真实音频可作 H1 例外。
2. **hook 有明确内容**：能力现场、真实痛点或问题均可；首帧非空，不强制首帧运动。
3. **强调服务层级**：一句至多一处关键强调，可用色彩、字重或位置，不每句强塞品牌色。
4. **动静有分工**：2–6 秒一段是起点；核心操作因果、真实结果和结尾需要读稳，允许有意静止。较长镜头在分镜写目的，不为切而切。
5. **音乐支持重点**：段落切换 / 重大成果可对齐重拍；打字、点击反馈、路径和阅读不强制吸拍。
6. **数字不编增长**：CountUp 可突出真实终值；展示两次变化需有两次统计与日期。无数字用成果，不编“还在涨”。
7. **成果不伪造规模**：作品墙或空间展用真实产出；不重复充数、不暗示未证实用户量 / 产能。品牌原则与愿景明确是主张。
8. **首尾呼应**：结尾复用母题 / 构图逻辑，官方 logo、定位、CTA 与网址出齐后完整停留 ≥3 秒；可以完全静止。

## 分镜自检

- 标题连读通顺，陌生人能理解“产品做什么 → 得到什么”。
- 各能力有真实 UI / 结果，数字和证言有来源；主张不充证据。
- 相邻镜头有构图与密度变化，联系表不是一直居中字、满屏网格或旋转面板。
- 各空间镜头能说明必要性、材质 / 灯光与相机揭示目标，并有清晰回 UI 的计划。

## 专属检查项

- [ ] 开头约 4 秒能认出产品类别，官方标识在 8 秒内出现
- [ ] 标题连读通顺、短而可读；有意阅读停顿没被节拍挤掉
- [ ] 方向静帧、黑白缩略图、整片联系表、参考并排看过
- [ ] 正常速度有声和静音各看过；没有无信息空等，也没有不必要持续运动
- [ ] 空间、材质、镜头服务内容，主 UI 清楚，回真实 UI 无跳变
- [ ] 作品 / 数字 / 证言真实，品牌原则不被包装成已验证效果
- [ ] logo + 定位 + CTA + URL 出齐后完整停留 ≥3 秒
- [ ] 总时长与约定一致（误差 ±1 秒），多画幅按同时间轴重排
