# 动效、排版与镜头数值

目录：排版 · 常用动作起点 · 确定性曲线 · UI 弹簧 · 运动模糊 · 光标与点击 · 时长与收尾 · 停留与抖动 · 转场与镜头 · 音乐对齐 · 音效与响度 · 克制与边界

以 1920×1080、30fps 为起点；其他画幅按布局重排并检查实际阅读尺寸。所有运动由帧 / 时间决定，可重复渲染。**曲线选择来自动作目的，不来自“弹簧一定高级、固定曲线一定廉价”的判断。**

## 排版

| 元素 | 字号起点 | 备注 |
|------|----------|------|
| 超大数字 | 160–220px | 数字有真实出处；「+」号可用品牌色 |
| 主标题 | 64–96px | 一屏一句，中文通常 ≤ 12 字 |
| 章节大字 / 原则卡 | 96–140px | 原则卡是品牌表达，不是效果证据 |
| 副标题 / 说明 | 24–32px | 通常 ≤ 25 字；以实际对比决定颜色，不机械压到 60% |
| HUD / 标签 / 注释 | 16–20px | 不为了复杂感堆小字 |
| 最小字号 | 16px（竖屏 28px） | 只是工程下限；投放尺寸仍需实看 |

- 横版四周留白以 96px 为起点；竖屏按目标平台、版位及实际预览设置安全区，不用固定上 85% 替代检查。出血作品可以越界，标题 / CTA 不可以。
- 重要标题可居中、上 1/3 或偏心，服从视觉母题；通常标题 + 说明两级，必要注释另设清晰信息区。
- 字体按角色选择，不强制多字体；标题、数字 / 等宽角色可以同族。先加载、测量，再排版（见 `type-motion.md`）。
- 3D 中细字不承担核心阅读；相机落定、主体正视后再展示完整 UI 和结果。

## 常用动作起点

文字方式见 `type-motion.md`；以下是起点，不是每镜头都必须使用的清单。

| 动作 | 参数 / 适用边界 |
|------|-----------------|
| 逐词淡入 | opacity 0→1，可选 blur 12px→0 / translateY 12px→0；400–500ms，词间 60–90ms；中文 2–4 字一组 |
| 卡片响应式入场 | scale 0.94→1 / translateY 24px→0，可用 `SPRINGS.default`；稳重舞台也可无过冲 ease-out |
| 多元素错开 | 80–120ms 起点，按层级和阅读量调，不让每个元素都跳一次 |
| 漂浮 | 需要表现悬浮时才用 ±6–10px / ±1°、6–10 秒周期；阅读停留可完全静止 |
| 慢推近 | scale 1→1.04–1.08 或相机推近；必须有聚焦目的 |
| CountUp | 1–1.5 秒 ease-out，千分位；终值停 ≥0.5 秒，未核实增长过程不编第二个值 |
| 图表生长 | 600–800ms，条间约 100ms；动画不能改变数据比例 |
| 高亮切换 | 背景色与文字色同步 250–300ms；遵循真实 UI 状态 |

## 按目的选择确定性曲线

| 动作目的 | 优先策略 | 要避免 |
|----------|----------|--------|
| UI 按下 / 开关 / 抽屉 / 多次改目标 | 产品 motion token 或 `motion.js` 闭式弹簧 / `track()` | 每次换目标重置造成顿挫，或比真实 UI 更夸张 |
| 标题 / 数字 / 信息重新排版 | 无过冲 ease-out / `heavy` / 显式关键帧；以读稳为终点 | 字体弹跳、缩放回弹导致难读 |
| 相机推拉 / 侧移 / 绕行 | 确定性 ease-in-out、分段速度曲线、停留关键帧；明确起落构图 | 把相机当按钮弹簧，碰到终点又回弹 |
| 路径运动 / 巡视成果 | 按距离组织速度，需要匀速时用线性；转向和速度衔接连续 | 参数匀速却视觉速度忽快忽慢，无目标绕圈 |
| 遮罩 / 线条 / 材质揭示 | ease-out / 匀速 / 自定义确定性曲线，按视觉意图选 | 一律加弹性，造成遮罩越界或材质闪动 |
| 阅读 / 对照 / CTA | 固定状态，留足可读停顿 | 为满足“持续运动”强行漂背景或转相机 |

确定性 `cubic-bezier` / 插值 / 关键帧可以用于位移，只要显式由时间采样；禁的是依赖实时 CSS transition、计时器或随机增量积分。Three.js 的相机与状态实现见 `three-workflow.md`，不要把帧内自由运行的物理模拟当确定性动画。

## UI 弹簧（可选，不包办全片）

`templates/motion.js` 提供时间纯函数的闭式弹簧与多目标叠加：

| 预设 | 用在 | 过冲参考 |
|------|------|----------|
| `snappy` | 按钮、开关、菜单、需要灵敏跟手的光标 | ≈0.5% |
| `default` | 卡片、容器、面板的响应动作 | ≈0.15% |
| `heavy` | 稳重标题、大数字、logo 的无过冲落定 | 0 |
| `playful` | 品牌允许的吉祥物 / 贴纸 | ≈8% |

- **文字读稳优先**：用 `heavy` 或无过冲曲线，不自动用 UI 弹性。
- **需要连续多次换目标时用 `track()`**：光标、容器尺寸等每次变化叠加新响应，避免换目标帧重启动效。时间轴明确的排版或镜头路径可用连续关键帧，不强制 `track()`。
- **收到 0 的尺寸夹到 ≥0**：弹簧过冲可能短暂为负，CSS 会丢弃负 width / height；写 `Math.max(0, value)`，防止“收起后又弹开”。
- 产品内部状态遵循自己的 motion token；舞台里的走位可以另设，但不能破坏真实交互因果。
- 让模型改动效时明确指出动作目的，例如“按钮更跟手；相机侧移无过冲；标题落定后静止 1 秒”，不说“所有 easing 都换成弹簧”。

## 运动模糊

快速位移 / 卡片飞入可能出现逐帧采样的生硬感；在需要的镜头短时间多采子帧平均，先测试最快的一镜，不默认全片加。

- **Remotion**：`@remotion/motion-blur` 的 `<CameraMotionBlur>` 包需要模糊的层，按速度调快门与采样数；不要给静止 UI 和阅读文字叠模糊。
- **HTML**：按输出帧率 3 倍渲染子帧，再每 3 帧平均，取以本帧为中心的采样：

```bash
# sub_00001.png… 按 180fps 渲染，输出 60fps
ffmpeg -framerate 180 -i sub_%05d.png \
  -vf "tmix=frames=3,select='eq(mod(n\,3)\,1)',setpts=N/60/TB" \
  -r 60 -c:v libx264 -pix_fmt yuv420p -crf 18 out.mp4
```

采样增加会放大成本；6 子帧需同步修改平均与选择参数。切点、片头片尾避免跨场景混合。3D 景深与模糊不用于掩盖低分辨率纹理；主 UI 要在正常速度下看清。

## 光标与点击（跟手）

- 到位停 2–4 帧再按下；按下帧即界面反应帧，之后停约 3 帧再离开。点击和界面反馈不能为了吸拍被拆开。
- 涟漪固定在点击点，不跟光标；拖动物直接取光标坐标函数，不另缓动制造滞后。
- 输入 / 处理中 / 结果状态照状态清单推进；省略等待时间要清楚表达，不能假造产品响应性能。
- 将点击、拖拽、自动响应和阅读分别定时，不按固定比例拉满镜头；独立控件与手柄按事件分别驱动，未操作属性保持产品允许的不变状态。具体例子与逐帧检查见 `interaction-choreography.md`。

## 时长与收尾

- 删没信息的空等，保留阅读和表达所需停顿。方案阶段可调整时长；已约定硬时长时不得擅自缩短，先重分配信息与停留，确需改变再确认。
- 逐镜记录主要动作完成时刻与切出时刻，检查差值及其阅读 / 表达目的；不能为了等拍点提前结束动作，也不能把自然操作拉慢来填空。需要守住音乐段落时，调整入镜、动作启动或内容编排。
- 连续慢镜必须有可感知的信息推进，例如细节揭示到全貌；小幅缩放或微转动不自动算有效推进。快镜可在运动中接力，不必每镜先减速到零；长镜可跨拍，不因鼓点密集就全程同速快切。
- 非循环宣传片落版：logo / 口号 / CTA 在约 1 秒内到位，完整停 3–4 秒可作起点；是否淡黑服从投放与方向，不强制。循环片用 `formats/hero-loop-6-15s.md` 的接缝规则，不加落版或淡黑默认值。
- 配乐跟着剪辑重剪：在拍点前的安静处切（两侧都选重拍前几十毫秒），10–20ms 交叉淡化；结尾优先接曲子自己的终止段，而不是在中段硬淡出；改长度后重测 −14 LUFS。

## 停留与抖动

- 阅读停顿允许整帧静止，并在分镜标明起止与阅读目标。没有设计目的的空等需要缩短，有信息的停留不要用漂浮填满。
- **弹簧落定锁值**：闭式弹簧尾部残差会导致小图标和影子重新栅格化；`motion.js` 的 `spring()` 已内置到位锁定。其他曲线和相机也在到位后返回精确终值。
- **交叉淡化避免双影**：共享阴影独立放底层，只淡内容，避免重叠时影子忽深忽浅。
- 用 `python3 scripts/still_diff.py out/video.mp4 --from <秒> --to <秒> [--region x,y,w,h] [--ignore 光标区域]` 检查设计上静止的区域；同帧重复渲染另用图片模式比较。真实视频继续播放时不要要求整帧 0 变化。
- 缩放文字出现栅格抖动时可试 `will-change: transform`，同时检查清晰度和显存成本；不要凭加了属性就判通过。相机空间段结束后可匹配切到正视 DOM，恢复细字清晰。

## 转场与镜头

- **下限是信息关系，不是技法复杂度**：不把无信息的卡片滑动、淡变或缩放机械重复整片。硬切适合换论点，匹配剪辑适合关系接力，相机连续运动适合真实空间关系，光揭示适合建立材质和注意力；淡变可表达时间或状态过渡，但避免 UI 双影。每次选择写明连接了什么，不默认排出 3D 高于 2D 的优先级。
- 每个转场在动画关前先出 3 帧（起、中途、落）给自己看：中途帧最容易失控（窗口斜着撑满画面、贴着镜头擦过），加中间关键帧压住。
- 默认先想连续关系：位置匹配、形状对应、构图呼应。
- 明暗硬切可对重拍或段落节点；必要时为叙事和阅读偏离节拍，在分镜写原因。
- 跨镜延续元素在衔接帧的位置、缩放、裁切、透明度和内容状态一致；空间→真实 UI 还核透视、颜色与材质退出。
- X1 / X2 等匹配剪辑的起点用运行时实测（`getBoundingClientRect` 或逻辑坐标换算），不要手猜像素。
- 颜色插值先看中间态；出现脏色可用移动的强调元素带过去，不机械禁止所有色变。
- 相机运动必须揭示主体、关系或结果；主体转、相机转、背景漂三者不要无目的叠加。固定镜头、稳定停留同样是镜头语言。

## 音乐对齐（节拍服务叙事）

- 曲风 / BPM 按品牌与片型选；100–125 BPM 的清晰器乐可作宣传片起点，不是硬限制。片头约 0.5 秒淡入，片尾 1–1.5 秒淡出。
- **先定音乐剪辑再排时间轴**：确定使用段落与拼接后，`scripts/analyze_music.py bgm.mp3` 输出 BPM、节拍、能量和 drop 候选；分析工具的依赖按实际环境准备。曲库已给 BPM 时可用 `--bpm`。记录源音频偏移和剪辑版本，原曲时间不能直接当最终音轨时间。
- 分三层编排并审看：**段落**对应乐句和能量变化，**切镜**对应重要重音或有理由的偏拍，**动作落点**对应合拢、整理完成等结果瞬间。切镜踩拍不代表动作同步；不得为对齐结果而破坏真实操作速度或因果。
- 小节首拍是推测，人工核听或 `--downbeat` 指定；自己编排的 loop 可直接记录首拍。需要用户试听时并入既有确认点 1，不多设确认。
- drop 候选基于能量，不替代听感；无明显 drop 的音乐不强造高潮。
- 用小节组织宏观段落，例如 120 BPM 的常见 4/4 拍一小节约 2 秒；品牌亮相、重点硬切、重大成果可用 `snapToBeat()` 对齐。
- **不要求每个动作吸拍**：打字、拖拽、点击反馈、相机路径和阅读时间由因果 / 清晰度决定。最大揭示适合高潮时可对齐，不必硬塞在第一拍。
- 换曲后重新听宏观段落与关键同步点，必要时调整时间轴；不是简单换文件，也不是机械把全部时间码重吸附。
- **画面收静不等于配乐降音**：无旁白、产品音频或明确声音设计目的时，不默认降低整段音乐。确需让位时，按被遮蔽内容调整增益与平滑过渡，记录区间及原因；不套固定的大幅压低值。

## 音效与响度

- 峰值对事件，不是文件开头：`analyze_music.py --peak whoosh.wav` 得偏移；起点 = 事件时间 − 偏移。
- 音效一般比音乐低 6–10 dB，只给关键动作，不每步都加。音乐、音效核商用授权。
- 社交导出可按 -14 LUFS，官网 / 发布会约 -16 LUFS 作起点，具体服从投放要求；ffmpeg `loudnorm` 归一，真峰值控制在 -1 dBTP 以内。
- 对有增益处理的片段核对包络与原曲相对变化，检查切点突变，并实际试听前后连续片段；整片平均响度合格不能证明局部无突兀降音。仅修改画面且用户要求音轨不变时，复用音轨并核对数据与时间戳，但画面重定时后仍须检查音画关系。

## 克制与边界

避免标题打字机、文字弹跳、炫技 3D 翻字、装饰性霓虹 / 粒子 / 冲击波、RGB 分离、无目的抖镜、闪烁背景、默认网格地板。真实空间需要的边缘反射、材质高光、阴影与适度景深可以保留；判断标准是是否解释空间、支持品牌且不损害清晰度，不是一概禁效果。
