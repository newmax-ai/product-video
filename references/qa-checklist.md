# 自检清单

## 目录

- 自评循环
- 内容与真实性

- 空间、材质与镜头
- 节奏与声音

- 常见反馈

先渲染，再打开实际画面。联系表不能代替正常速度观看，模板可运行也不等于整片通过。真实性、授权、隐私与确定性是底线；其他项目按用户约定、片型规则、通用推荐依次适用，不适用项写理由。

## 自评循环（每道制作关卡执行适用项）

1. **抽帧**：每镜头取入场中途、最满 / 代表性构图、出场前各一帧；切点前后各一帧。阅读段加读稳帧，空间镜头加最大遮挡 / 最斜视角。实际 renderStill 或 seek 截图，不凭代码想象。
2. **看四种对照**：黑白缩略图检查层级；整片联系表检查构图、明暗、密度与空间变化；与参考并排检查尺度、材质与转译；动画关可补每拍一帧联系表，但不要求每拍都动。
3. **逐镜评分**：以下六项各 1–10 分；2D 镜头也检查表面角色与层级，不强加 3D。

| 维度 | 8 分的样子 |
|------|-----------|
| 可读 | 实际投放尺寸下主信息清楚，无出界 / 遮挡，阅读时间足够，透视与模糊不毁细字 |
| 证据 | 真实 UI / 结果 / 有来源图表支撑能力；模拟、品牌主张与已验证事实分开 |
| 还原 | UI 状态、间距、字体、图标等与真实基准一致，作品没有被替换 |
| 构图 | 主次、网格、留白有意图，黑白与相邻镜头对照仍成立 |
| 空间材质 | 维度选择有理由，表面光影支持母题；3D 有几何、体积、遮挡与接触 |
| 节奏衔接 | 正常速度可读，动作有目的，状态连续，不为吸拍破坏因果 |

4. **正常速度观看**：有声音的片型有声和静音各看一次；无声片不虚构声音检查。必要时按真实手机 / 页面显示尺寸播放，检查叙事、操作、阅读与镜头速度。
5. **写最差 3 个问题**：镜头号 / 时间码 / 可见现象 / 改法。先诊断层级、构图、材质、节奏，不统一减元素。
6. **优先修这 3 个**，重渲相关镜头并回看整片；真实性或技术阻断项不能因不在前三而跳过。
7. **停止条件**：所有适用项 ≥8，且技术、真实性、授权无阻断项。连续两轮不升时交出对应帧和未解决问题，不标“验收通过”。每轮记录在 `CRITIQUE.md`；未观看或未执行的项标待验证。

## 内容与真实性

- [ ] 开场有信息，钩子与产品出现时机符合片型；不强迫首帧运动
- [ ] 标题连读通顺，每条能力有真实证据
- [ ] 数字、图表、证言、客户 logo 和作品有出处、口径、日期与使用许可；不重复作品伪装规模
- [ ] 品牌愿景与原则是主张，不包装成测评或已验证结果
- [ ] 官方 logo 不重画；UI 来源与状态可对照，氛围图不冒充产品 / 作品
- [ ] 等待缩短、流程抽象与演示数据有说明，不误导响应速度；模拟成功不证明实际执行成功
- [ ] 采集实例已确认，敏感内容已脱敏；没有改写用户真实记录或触发未授权外部操作

## 美术、可读性与画面

- [ ] 确认点 1 已给 2–3 个方向与代表静帧，记录选择；母题、构图、密度、空间、材质、光影与镜头不是只有色号
- [ ] 黑白缩略图主次明确；联系表有构图 / 密度变化；与参考并排检查过尺度、空间、材质和转译
- [ ] **分别验三件事**：① 成片字号：正视 DOM 用 computed font-size × 最终屏幕缩放计算，1080p 正文 18px、竖屏 28px 仅作起点；字形墨迹高度 / 行高不能直接当 font-size。② 素材分辨率：检查贴图 / 截图在最大显示面积下是否足够清晰；原生 1× 不等于可读。③ 投放可读性：实际播放尺寸、透视、压缩和停留时间下确实读得清。纯位图无字号元数据时记录测量方式，不伪造精确字号
- [ ] 放大的是需要讲的组件；整体窗口可交代上下文，但缩小细字不承担阅读。裁切不破坏操作因果或必要内容
- [ ] **线不压字**：HTML 路线 `--overlap` 覆盖最终全部帧；选择器区分舞台标题、UI 容器与内部合法文字。每个必需来源（含独立的 3D 投影钩子）全程有可见采样、零违规且无 `overlapUnverified` 才算自动通过；可缺省来源明确配置和说明。复杂裁切的人工检查与自动状态分开，不能静默忽略。Remotion 等其他路线记录实际逐帧输出和适用检查，未接入的自动项标未验证
- [ ] 主题符合产品与方向；DOM 可保留壁纸，截图拆组件可选产品纯色主题并记录。主次通过灰度、构图和尺度核对，不强制舞台与 UI 达到统一 7:1，也不只靠阴影
- [ ] 导出 / 重建没有新增边线、裁切或字体回退；修正基于真实基准，不把产品本来有的细节随意删除
- [ ] 阅读段有清晰焦点；暗场、剪影与静止有表达目的，不机械要求主体永远最亮
- [ ] 停留服务阅读与表达，落定区域稳定；收尾时长按片型与约定，循环片无默认落版或淡黑
- [ ] 2D / 2.5D / 3D 选择支持镜头目的，丰富度来自关系、密度、材质与节奏，不一路旋转卡片

## 空间、材质与镜头（有空间镜头时）

- [ ] 空间必要性可解释；主体几何、前中后景、比例与遮挡可信，没有穿插或厚度突变
- [ ] 材质、粗糙度、透明和反射有角色；接触影与主光一致，不默认全玻璃。中性不受光侧壁只是修色边的可选策略
- [ ] 主 UI / 作品颜色比例真实，高光、景深、反射不损害证据；透视段不强迫读细字
- [ ] 相机路径揭示信息，速度 / 裁切无突变，没有无目的绕圈或晕镜
- [ ] 抽象承托不伪装真实硬件，分层图不冒充内部架构证据
- [ ] 回真实 UI 的位置、尺寸、透视、圆角、颜色与状态匹配；`--handoff` 仅生成差分和掩膜，必须逐张看过，数字为零不自动证明开关有效
- [ ] 有面板时执行 `--corner`，FRONTAL / COLOR 为 0 且有有效采样；缺钩子或零采样是未完成。另看 200–400% 圆角裁切；没有此类面板才标不适用
- [ ] 转场有信息关系，不按技法复杂度评高低；检查起 / 中 / 落及切点，不能用复杂运镜掩盖失控构图
- [ ] 空间后有清晰的正视阅读 / 操作；资源、字体、纹理加载完成，在实际导出环境抽帧验证过

## 节奏与声音

- [ ] 切镜 / 停留符合片型与阅读量，静音仍能理解主线；功能讲解另验配音和字幕
- [ ] 重点与音乐关系明确，点击 / 拖拽因果不被吸拍拆开
- [ ] 有配乐时首拍、高潮人工核听；无突然截断，淡出按用途决定，换曲后重看全片
- [ ] 音效峰值对事件、不过密、不盖人声；响度按投放约定，社交 -14 LUFS 可作起点
- [ ] 音乐、音效、字体、图片、模型、纹理授权覆盖用途
- [ ] 时长符合确认的容差；未另定时 ±1 秒可作起点，硬广告档期从其要求。变更时长不能直接拿旧约定判通过

## 导出与确定性

- [ ] H.264、yuv420p、CRF 18 左右、AAC 192k 可作默认；ffprobe 验分辨率、帧率、时长，无声片按约定
- [ ] 快速运动按需测试模糊，无明显频闪，UI 和字不丢清晰度
- [ ] 字体字符齐全且已加载；图像、视频、空间纹理解码就绪，无空白或上一帧残留
- [ ] 任意跳帧正确；同环境新进程重复渲染 UI 帧和空间帧（若有），比较一致性并注明容差
- [ ] 资源、种子、时钟与相机受控；静止区用 still_diff.py 检查，按分镜排除真实运动内容
- [ ] 多画幅重新排版而非裁切；海报帧、联系表、分镜、CRITIQUE.md、工程重渲说明齐全
- [ ] HTML 路线按 `render-validation.md`：最终默认完整重渲，用本次独立报告目录及 `--expect-frames` 汇总；分片全部完成、覆盖完整、输出图片哈希一致。局部测试或纯渲染不算全片质量验收
- [ ] 显式续跑仅限未变的源 / 素材版本和参数；修改后不能继续使用旧 revision 复用帧
- [ ] Remotion 使用原生渲染及对应的验证链，不宣称 HTML 检查脚本已经覆盖它
- [ ] 编码只使用已验收的帧区间，避免旧目录中多余尾帧进入成片；最终检查编码后的视频而非只看 PNG

## 常见反馈

| 反馈 | 先诊断，再改 |
|------|--------------|
| 太快 / 字太多 | 定位没读完的信息，分层、拆镜或延长具体停留，不缩成小字、不机械全片加时 |
| 不够高级 / 太平 | 先看主次、密度、空间接触、材质光影、相机与动静节奏，不一律减元素或加粒子 |
| 3D 太假 / 晕 | 查几何、厚度、接触、粗糙度、灯光与相机；回正视 UI，不靠辉光掩盖 |
| 圆角有色边 | 定位帧与面板，核对轮廓、投影和机身内缩；必要时采用中性侧壁，不能不看图只靠计数 |
| 线压字 | 核对选择器和真实遮挡，再改布局 / 图层；不把 UI 内部正常文字当舞台标题 |
| 转场廉价 | 找出缺失的内容关系，试硬切、匹配、空间或光揭示，选最清楚且符合方向的一种 |
| 结尾拖沓 | 删无信息空等，保留真实阅读时间；循环片修接缝，不套 CTA 停留 |
| 音乐不搭 / 不像产品 | 回到品牌情绪、真实 UI 与结果；换曲重核节奏，不只换色或换文件 |
