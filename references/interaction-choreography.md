# UI 交互编排：事件、跟手与结果

用于点击、拖拽、滑块、路径编辑与自动整理镜头。先验证真实产品或明确标注的原创演示，再编排确定性动画。演示应用可运行，只能证明该演示的行为，不能证明被宣传产品拥有对应功能。

## 1. 先建立事件表，不把两张状态图直接插值

按 `templates/storyboard.md` 记录：目标控件、接近 / 按下 / 移动 / 松开时刻、受影响属性、必须保持不变的属性、反馈和结果。状态 diff 只列候选差异，不能推断因果、先后或耗时。

**事件表是实现与验证依据，不是成片必须完整展示的步骤表。** 宣传片保留说明能力所需的关键行为，允许省略无关导航、从明确的操作中段切入、在结果成立后切出；不能伪造因果，隐藏必要步骤或把剪辑压缩冒充性能。先按片型判断观众需要理解价值还是学会操作，不用慢放、等待文案或固定每次点击时长代替这个判断。

- 同一操作的真实联动属性按产品行为同步；独立操作使用独立事件区间和进度。
- 不同动作可以使用不同响应曲线，不能用一个镜头总进度驱动全部控件。
- 按绝对帧计算完整状态；任意跳帧仍能还原选中项、按下状态、参数值和光标位置。
- 优先采用真实交互录制、产品 motion token 或可运行源码作为时间依据。原创演示先实际操作，再制作原速小样；不存在统一的“每个 UI 镜头持续几秒”。

## 2. 按操作类型编排

| 类型 | 正确的因果 | 重点检查 |
|------|------------|----------|
| 点击整理 | 光标到位 → 按下反馈 → 布局响应 → 结果可读 | 响应由点击触发，不在光标到位前自启动；短布局响应不能被拉长成整段滑行 |
| 拖动卡片 | 按下抓取 → 跟手 → 松开 → 按产品规则吸附 | 拖动期间物体与指针抓取点的相对位置固定；仅松开后允许独立吸附曲线 |
| 独立滑块 | 调整当前参数 → 松开 → 换位 → 调整另一参数 | 未操作参数保持不变；换位期间无误按，不能共享拖动进度 |
| 路径 / 手柄编辑 | 选中手柄 → 拖动 → 相关曲线变化 → 松开 | 仅改变产品约束实际关联的控制点；保留对称 / 平滑约束，不让无关图形整体变形 |
| 输入 / 异步处理 | 输入 → 提交 → 真实处理反馈 → 结果 | 输入速度和处理耗时分开；缩短真实等待需注明，不把演示耗时当性能证据 |

画面需要跨拍时，让真实操作自然完成，再重新安排镜头或音乐关系；不能为填满分镜而减慢人的手势、延迟反馈，或在结果之后补无信息停顿。

## 3. 跟手坐标与独立状态

在同一坐标系计算指针和物体。设抓取瞬间物体原点与指针的偏移为 `grabOffset`，按下期间使用 `objectPosition = pointerPosition + grabOffset`；如果舞台有缩放、透视或相机运动，先完成一致的坐标换算。物体本身不能再叠加独立缓动造成滞后。

多控件测试例：

1. 第一滑块拖动期间，第二参数等于初值。
2. 松开换位期间，两个参数保持不变，按下状态为假。
3. 第二滑块拖动期间，第一参数等于已设定终值。
4. 结束后指针释放，所有结果保持产品允许的状态。

局部编辑测试例：选中控制点变化；未关联控制点不变；路径符合产品约束。不要为了满足“只改一点”破坏真实的联动规则。

## 4. 时长与可读性分开处理

把镜头拆成接近、操作、响应、结果阅读，而不是按固定百分比分段。减少无意义的接近路径；拖拽速度服从可观察的真实手势；自动响应服从产品行为。

结果需要阅读时明确阅读对象和所需停留。读不清优先改变取景和信息量，不把操作本身慢放。省下的时间可重排内容或经约定调整总长；新增作品必须服务叙事，不能为凑时长机械加镜头。

按钮使用产品布局规则；原创演示按钮按文字和图标组合计算对齐。检查空闲、按下、完成等不同文案，不能用固定文字起点硬套不同字宽；光标不得遮住关键反馈。

## 5. 在整片制作前验原速小样

选择各类高风险交互，输出正常播放速度的诊断短片；诊断材料连续包含操作前状态、按下、响应、松开与结果，便于核对因果，不用抽帧拼贴代替运动。**诊断短片不等于宣传片样片**：手势正确后仍须放回有用途、前后镜头和成果的叙事片段验收；不能反复只交孤立点击片段，就认为整片表达已修复。

- **状态检查**：实际点击 / 拖动验证产品或演示；逐帧或事件边界断言独立参数、抓取偏移、触发先后和松开状态。已有工程测试优先复用。
- **画面检查**：看实际帧中的按钮对齐、光标遮挡、控件状态和坐标映射；状态值正确不等于渲染画面正确。
- **动态检查**：正常速度判断接近是否拖沓、拖动是否跟手、响应是否自然、结果是否读得清；嵌入前后镜头检查交接是否空等。

记录片段路径、时间码、观察者与具体问题。程序断言、播放器 `ended` 事件、技术解码和主观手感是不同证据；没有实际观看不能填写“操作自然”。未具备审看能力时交待审样片并说明需要确认的具体点，不默认为动态关通过。
