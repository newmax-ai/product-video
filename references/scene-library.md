# 镜头库

每种镜头：用途 → 画面 → 动作 → 技术边界。时长为建议值；文字见 `type-motion.md`。按镜头目的选择 2D / 2.5D / 真实 3D，空间不是全片默认配置，也不等于把卡片旋转。视觉系统见 `creative-direction.md`，真实 3D 工程见 `three-workflow.md` 和 `templates/three/`。

| 类 | 镜头 |
|----|------|
| 开场 | H1 能力现场演示 / H2 信息潮水 / H3 情绪问题 |
| 品牌 | B1 Logo 揭示 / B2 品牌 + 作品环绕 |
| 导航 | N1 章节目录滚轮 / N2 章节卡 |
| 能力 | F1 输入→输出 / F2 结果散开 / F3 流程节点 / F4 章节卡+演示 / F5 放大镜核实 / F6 图表拆解 / F7 多语言切换 / F8 参数+样例轮播 / F9 产出类型轮播 / F10 单形状变形串联 / F11 预览窗放大 / F12 规则卡轮播 / F13 跨端接力 |
| 空间 | G1 主体亮相 / G2 界面分层 / G3 成果展览 / G4 3D 回到真实 UI |

## 开场类

### H1 能力现场演示（2–4s）
- 用途：产品能出声、出图、出字，直接让它做一次。
- 画面：小标签（如「产品生成的声音」）+ 真实生成效果 / 过程 + 一句字幕。
- 动作：字幕按词高亮，声波与真实音频同步；看清结果后可短停。
- 边界：标签中的「实时」等性能词必须有依据，不用缩短等待的演示冒充实测；宣传片的产品人声例外用真实输出。

### H2 信息潮水（2–4s）
- 用途：痛点是太多、太乱。
- 画面：真实标题 / 条目多行滚动，中央大字明确问题。
- 动作：内容向中心收拢或淡出，留一行引出方案。
- 边界：密集文字表现痛点，不把不可读小字当功能证据；突出主标题与下一步真实 UI。

### H3 情绪问题（3–5s）
- 用途：面向创作者或个人用户。
- 画面：风格统一的氛围插画 + 两行问句。
- 动作：可慢推近（5 秒约 3–5%），或固定镜头让问题读完。
- 边界：插画可 AI 生成，但只能作氛围，不是假用户、真实作品或产品实物证据。

## 品牌类

### B1 Logo 揭示（2–3s）
- 用途：名字与视觉母题建立联系。
- 画面：官方 logo / 字标在品牌底上出现，构图呼应前后镜头。
- 动作：0.9→1 的无过冲缩放、遮挡揭示或直接落定；副标题约 0.5 秒后出现。
- 边界：不重画 / 改造官方 logo；不默认同心圆冲击波或辉光。空间亮相可改用 G1，logo 本身仍保持品牌比例。

### B2 品牌 + 作品环绕（3–4s）
- 画面：logo、slogan 与 5–7 张真实作品形成主次关系，可偏心、不强制居中；少量倾斜 −8°～8°。
- 动作：作品错开 80–120ms 到位，slogan 出现后给阅读停留；漂浮仅在母题需要时用。
- 边界：作品不抢主标题，阴影与材质统一；环绕作品只能证明这些结果，不能暗示用户量。结尾可复用构图。

## 导航类

### N1 章节目录滚轮（1.5–2.5s）
- 用途：多章节长片说明现在与后面讲什么。
- 画面：固定短词 + 竖排章节名，当前项高亮；底色按视觉系统与内容明确区分。
- 动作：每次滚一格并停留，见 T4。
- 边界：导航不是必用黑底，也不让目录运动挤掉可读时间。

### N2 章节卡（1.5–2s）
- 画面：图标 + 功能名（通常 ≤3 词），可用偏心网格或居中版式。
- 动作：图标先出，文字 T2 或无过冲揭示，随后进真实演示。
- 边界：短章节卡服务导航，不拖成没有内容的品牌秀。

## 能力类

### F1 输入 → 输出（3–5s）
- 标题 + 真实输入框 / 主按钮，演示真实输入。
- 光标到位、按下即反馈 → 处理中 → 真实结果；容器可变形，或匹配切到结果。
- 边界：输入框可打字，标题不打字；轻倾斜是 2.5D，必须读得清，关键操作回正视。不靠卡片翻转掩盖缺失的状态。

### F2 结果散开（2–3s）
- 一个真实结果扩展到多份有来源结果，排成有层级的网格。
- 可按 UI 响应用弹簧，也可稳定曲线展开。
- 边界：“一次能出很多”要有真实能力支撑，不能重复一张图假装独立产出。

### F3 流程节点（3–5s）
- 3–4 个编号节点 + 动词，连接线依次强调当前步骤。
- 动作可按叙事顺序，不强制每节点占一拍。
- 边界：节点代表真实流程；必要处补 UI / 结果，不只画抽象流程声称已证明能力。

### F4 章节卡 + 演示（2s + 3–4s）
- 「◆ 动词」+ 说明，再进入左字右 UI 或按母题配置的组件展示。
- UI 内容依次出现：输入、进度、回答或结果；角落留章节号。
- 边界：真实状态与来源可追溯，氛围图不抢证据。

### F5 放大镜核实（3–5s）
- 用途：可信、有出处、精读。
- 真实原文作底，透镜沿阅读区域移动，显示实际解读与来源。
- 边界：放大内容来自真实文档；路径平稳确定，不编引用或在镜内偷换结论。

### F6 图表拆解（3–5s）
- 有来源条形图生长，结论数字最后出现，底部标来源和口径。
- 约 600–800ms 生长、条间 100ms，可用无过冲 ease-out。
- 边界：如「3.1×」必须有依据；动画、透视与比例不能夸大比较。

### F7 多语言 / 多端切换（2s 起）
- 分段切换器选中项切换，下面真实对应界面同步变更，淡换不打字。
- 边界：用产品实际支持语言 / 端；给每版标题读完的时间，不为了 2 秒硬塞多组。

### F8 参数 + 样例轮播（3–5s）
- 顶部真实参数，下面 3 张真实样例依次强调，当前卡出现声波 / 字幕。
- 边界：参数有来源，样例源于该能力；需要听或读的样例可延长停留。

### F9 产出类型轮播（每类 1.5–2s 起）
- 左侧类型名 + 分页，右侧真实产出大图；可以斜向入场，但最终构图稳。
- 边界：每类有独立真实示例；复杂作品不按快切时长机械处理。

### F10 单形状变形串联（6–15s，可作主线）
- 用途：多个能力连续展示，不做一镜一张幻灯片。
- 画面：单一主体在按钮 → loader → 播放器 → 滑块 → 图表 → 命令面板等真实状态间变形。
- 动作：先列状态与触发，按真实产品点击反馈推进；宽高、圆角可用 `track()`，或按目的的无过冲确定性曲线。内容在形状变化约一半后交叉淡换。
- **先状态清单**：标尺寸、圆角、底色、内容、触发与阅读时间。首屏循环末帧 = 首帧，状态、光标和资源都要闭合。
- **容器与内容错开**：旧内容先退、容器变、新内容再进，避免新旧字重叠。
- **尺度按阅读目的**：小状态适当靠近，复杂结果落定后读清；不每个状态都强制推拉。
- **指示条**：前后缘独立弹簧可表现跟手，但品牌稳重时整体平移也成立。
- 边界：不可暗示产品不存在的状态；短模糊仅用于快速转场，不糊结果。

### F11 预览窗放大成全屏产出（3–5s 起）
- 用途：证明在产品里完成，且产出足够好。
- 预览窗连续放大 → 真实产出全屏 2–4 秒或按阅读量停留 → 回 UI / 下一镜。
- 动作：无过冲 ease-in-out 或合适的 `default` 弹簧，圆角收至 0；其余 UI 淡出，尽量保持产出清晰。
- 边界：全屏只用真实录屏 / 导出文件；分辨率不足改大卡片，不放大糊图。可与 G4 配合。

### F12 规则卡轮播（4–6s）
- 真实触发条件卡 + 动作卡，中间箭头，2–3 组规则。
- 旧卡后退、新卡上来，左右可错开约 80ms；每组有读完的停留。
- 边界：例子是实际可配规则；服务 logo 核授权，不将未执行的配置当成功结果。

### F13 跨端接力（5–8s）
- 手机下真实指令 → 远端画面缩略 → 桌面任务执行 → 两端并排看同步状态。
- 两端用真实导出 / 重建界面，连接点可轻脉动。
- 边界：简洁通用手机框，不假造具体机型硬件；只取应用窗口，状态同步可核对。

## 空间类（按需与 2D 演示穿插）

### G1 主体亮相（3–5s）
- **用途**：建立产品的视觉记忆、空间规模与材质特征；适合品牌亮相或重大章节，不替代能力证明。
- **画面**：真实 UI 置于有厚度的抽象承托结构 / 工作台，主标题偏心，前景边缘、中景主体与后景环境形成层次。承托结构延续视觉母题，不默认做手机壳或发光卡片。
- **动作**：从部分遮挡或侧面开始，短侧移 / 绕行揭示主体体积，落定到清楚构图；灯光始终能读出表面与接触，留短停。下一镜进入真实操作。
- **技术边界**：需要真实几何、遮挡、法线、光照与相机时走 Three.js；仅 CSS rotate 不算此配方的完整实现。UI 来源为真实 DOM / 源码重建导出，保持比例和色彩。抽象舞台标明是视觉表达，不暗示真实硬件、物理产品或不存在的 3D 功能；模型 / 纹理 / 环境核授权。

### G2 界面分层（3–6s）
- **用途**：解释面板、工作流、输入与结果之间的层级关系，而非炫技拆散 UI。
- **画面**：从真实正视界面出发，把来源明确的几个组件分成有限深度层；连接和编号说明关系，细字不作为斜面核心信息。
- **动作**：界面先保持可识别，再沿深度展开；相机轻侧移揭示遮挡和层次，停在关系清楚的一帧；层合回原状态或接 G4。
- **技术边界**：简单已知层序可用 2.5D；要多角度遮挡、厚度与材质才用真实 3D。组件来自同一真实状态，拆分必须保留实际边界与内容，不能“设计”出新功能。保持有限层数、清楚连接与一致尺度；不把真实布局关系编造成产品内部架构或数据流证据。

### G3 成果展览（4–7s）
- **用途**：让观众观察产出质量、类型与关系，为密集成果段提供空间组织。
- **画面**：代表作品为主展品，其他真实成果分组陈列在有体积的展台 / 框架 / 屏面；近中远尺度明确，环境中性，不抢作品颜色。
- **动作**：沿预定路径巡视 → 到代表成果前减速并停留 → 选择一项推入真实产出或回产品 UI。视差和遮挡解释作品关系，不能只让同一张卡自转。
- **技术边界**：平面展墙可用 2D / 2.5D；有体积陈列、空间路径与真实遮挡才用 3D。所有展品有来源，重复展示不能充数量；若视频纹理不适合逐帧导出，按工作流预解码或用静态成果，并如实说明。景深 / 反射不糊主作品；陈列数量不代表用户量、一次生成量或性能。

### G4 3D 回到真实 UI（2–4s + 阅读段）
- **用途**：从品牌 / 空间展示回到可读、可操作的产品证据，避免全片都是斜面面板。
- **画面**：空间主体中的真实 UI 与下一镜正视 DOM / 重建组件使用同一状态、内容与裁切；到位后整个 UI 可清晰阅读。
- **动作**：相机与主体姿态收敛到正视，材质反射 / 景深逐步退出，界面四角与下一镜匹配；在落定帧接正视 UI，之后光标开始真实操作。可反向进入空间，但必须有叙事目的。
- **技术边界**：先约定衔接状态与屏幕坐标，再配相机，不手猜。匹配尺寸、位置、透视、圆角、裁切、颜色和时间；3D 表面用真实界面渲染资产，操作段恢复真实 DOM / 源码重建，不能靠两张不同 UI 截图长淡变掩饰跳变。逐帧与正常速度都核对；具体坐标和渲染实现按 `three-workflow.md`，不臆造模板 API。

## 成果、规模与品牌表达

### S1 作品墙（2–4s 起）
- 真实作品形成分组网格，主作品与标签清楚；2D、轻倾斜 2.5D 或 G3 空间展均可。
- 需要巡视时缓慢平移，关键成果留停。
- 边界：作品墙证明这些产出存在，不自动证明“很多人在用”；数量 / 覆盖范围有来源才写。

### S2 纵深巡视（3–4s 起）
- 真实作品沿有组织的纵深布置，相机前移揭示下一组，避免高速擦屏和无目标飞行。
- 编号 / 总数仅在真实统计口径成立时出现，不以成百张重复卡片假造规模。
- 边界：只靠平面视差可用 2.5D；完整几何 / 遮挡 / 光照用 G3。主作品不能小到无法辨识。

### S3 数字 CountUp（2–3s）
- 超大真实数字 + 单位 + 来源注释，终值读稳至少 0.5 秒。
- 多数字可错开约 100ms；有两次真实统计与日期才展示增长，否则只到一个终值。
- 边界：数字、单位和口径一致，不编“还在涨”。

### S4 用户证言（按阅读量，通常 ≥2s）
- 真实照片、身份、姓名、原意不变的引语按层级出现。
- 边界：只用获准使用的真实证言，没有就不做；不强迫长引语 1.5 秒读完。

### S5 原则卡（每张 1–1.5s 起）
- 品牌原则 + 简短解释 + 编号，纯色切换可作节奏强调。
- 边界：这是品牌愿景 / 承诺，**不是效果、规模、第三方评测或用户认可的证据**；不能替代前面缺失的功能实证。

## 延伸类

### E1 终端安装（2–3s 起）
- 真实安装命令逐字输入，回车出现实际成功输出；下方入口标签（CLI / SDK / API 等）。
- 边界：安装命令与输出需核对，未运行的示意注明演示；终端允许打字机，标题不允许。

### E2 订阅渠道（2s 起）
- 真实播放器 / 进度 / 期数与可用渠道标签（邮件、RSS、播客等）。
- 边界：渠道与期数真实；声波要与实际音频对应，不能凭噪声模拟质量证明。

## 转场类

### X1 词变成 UI（1–2s）
- hook 中某词原地变成真实输入框 / 搜索栏，接操作。
- 实测词的包围盒，按目的选无过冲曲线或弹簧，容器到 UI 的位置 / 尺寸 / 圆角连续；旧字前半退，新内容后半进。
- 边界：不是标题打字机，也不以变形代替真实 UI。

### X2 按钮张开成新场景（0.6–1s）
- 按下按钮后从实测按钮中心扩展遮罩，揭示下一场景；`clip-path: circle(r at x y)` 可由确定性曲线驱动。
- 可在段落重拍揭示，但点击反馈不能被吸拍推迟。点击接近镜头末尾，遮罩铺满立刻进入有内容的新场景。
- 边界：这是叙事遮罩，不是无意义冲击波；不让铺满后长时间只剩空底。

## 结尾

### End Card（3–5s 起）
- logo → slogan → 可选短主张 → CTA + 网址，主次清楚，构图呼应开场母题。
- 元素可间隔 150–250ms 到位，全部出齐后至少读稳 3 秒（片型另有约定时注明）；静止可成立，不强制浮动。
- 边界：主张如“可信、专业”不写成已验证效果；logo / URL 真实，缩略尺寸能读。可由 G4 回 UI 后落版，但不连做无目的空间镜头。
