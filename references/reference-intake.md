# 参考素材怎么用

没有参考时，模型会退回「默认脸」：渐变背景、居中文字、所有东西淡入、结尾放 logo。一张参考帧或一支参考片提供的节奏、字体和转场，比任何形容词都准。

**直接说出风格名，比描述风格好用**：写「瑞士国际主义排版」「Apple 发布会产品片」「Stripe Sessions 开场」「PC-98 像素风」，不要写「简洁高级有科技感」。

## 三种参考，三种接法

| 用户给的 | 先做什么 | 产出 |
|---------|---------|------|
| **一帧**（截图、海报） | 明确列出「要拿」（配色、字体气质、颗粒/纹理、构图密度）和「不要拿」（主体内容、别人的品牌元素） | 写进分镜表的风格 token |
| **一支视频**（文件或链接） | 先拆解再动手：`scripts/scene_cuts.sh ref.mp4` 取切点，`scripts/contact_sheet.sh ref.mp4 2` 每秒 2 帧出联系表，逐张看图，写出逐镜头表 | 与 `case-studies.md` 同格式的拆解表：时间 / 镜头 / 画面上的字 / 视觉证据与动作；外加「可学的点」3 条 |
| **一个素材库**（历史作品、品牌图库、设计稿文件夹） | 先让模型通读并写 `style_guide.md`：色板（从图里取 hex）、字体、构图习惯、反复出现的记号 | `style_guide.md`，后续所有镜头按它检查 |

参考片优先让用户直接提供视频文件。需要从平台下载时，先确认该平台的条款允许，不允许就请用户自己保存后给你；拿不到文件时，不要只凭标题和简介猜节奏。

**用户说不出参考时**，建议从这几处找，都不会失效，也没有授权顾虑：同类产品或竞品官网上的发布片；大公司产品发布会的视频；用户自己过去的作品和品牌素材库。

## 拆解参考片时要记下的数

- 总时长、镜头数、平均镜头时长（`scene_cuts.sh` 直接给）
- logo 第一次出现的秒数、CTA 停留秒数
- 主力入场动作（逐词模糊？卡片弹入？整屏硬切？）和一个镜头内同时在动的元素数
- 背景切换次数和切换落在哪些拍上
- 文字密度：一屏几个字、最多几级字号

这些数直接写进我们自己分镜表的约束，比「参考它的感觉」可执行。

## 边界

- 参考只借**方法和气质**，不照搬别人的构图顺序、文案、插画和品牌元素；拆解表里「可学的点」要写成我们自己能复用的规则。
- **参考片只用来拆解学习**：它的画面、配乐、音效和素材一律不能剪进成片。
- 给了参考后，**说清要的效果和约束，不要替模型指定实现库**（除非为了复用必须用某个框架）：参考片的纸张质感可能用 p5.js 做，也可能自己写一个渲染器更贴。
- 用户自己的素材库是别人抄不走的参考，优先级高于网上的爆款片——大家都照同一批爆款做，片子会彼此雷同。
