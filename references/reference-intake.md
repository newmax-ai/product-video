# 参考素材怎么用

没有参考时，模型会退回「默认脸」：渐变背景、居中文字、所有东西淡入、结尾放 logo。一张参考帧或一支参考片提供的节奏、字体和转场，比任何形容词都准。

**用可观察的视觉规则替代空泛形容词**：风格名可作为研究检索词，但随后写成网格、密度、材质、镜头与节奏规则；不把「像某品牌那支片」当复刻指令，也不只写「简洁高级有科技感」。

## 三种参考，三种接法

| 用户给的 | 先做什么 | 产出 |
|---------|---------|------|
| **一帧**（截图、海报） | 明确列出「要拿」（配色、字体气质、颗粒/纹理、构图密度）和「不要拿」（主体内容、别人的品牌元素） | 写进分镜表的风格 token |
| **一支视频**（文件或链接） | 先拆解再动手：`scripts/scene_cuts.sh ref.mp4` 取切点，`scripts/contact_sheet.sh ref.mp4 2` 每秒 2 帧出联系表，逐张看图，写出逐镜头表 | 与 `case-studies.md` 同格式的拆解表：时间 / 镜头 / 画面上的字 / 视觉证据与动作；外加「可学的点」3 条 |
| **一个素材库**（历史作品、品牌图库、设计稿文件夹） | 先让模型通读并写 `style_guide.md`：色板（从图里取 hex）、字体、构图习惯、反复出现的记号 | `style_guide.md`，后续所有镜头按它检查 |

参考片优先让用户提供有权用于本次分析的文件。访问、下载和处理都遵守平台条款与授权；拿不到时用获准公开观看或文字分析，不让用户代为绕过限制。只有标题、作者说明或视频元数据时，明确标为文字层证据，不猜镜头、节奏、字体与转场；实际看过才填逐镜头表。

**用户说不出参考时**，可研究同类产品官网发布片、公开发布会和用户自己的品牌素材库。链接可能失效，公开可见不代表有复用授权；先确认用途，用户自有资产也核第三方字体、音乐与图片的权利。通用制作方法与已查来源见 `product-video-methods.md` / `product-video-sources.md`。X 等渠道是寻找作品和经验的参考来源，不是默认发布目标；不要把研究来源转化为成片的平台、画幅、时长或运营要求。

## 拆解参考片时要记下的数

- 总时长、镜头数、平均镜头时长（`scene_cuts.sh` 直接给）
- logo 第一次出现的秒数、CTA 停留秒数
- 主力入场动作（逐词模糊？卡片弹入？整屏硬切？）和一个镜头内同时在动的元素数
- 背景切换次数和切换落在哪些拍上
- 文字密度：一屏几个字、最多几级字号

这些数用于解释参考如何工作；转化成适合本产品的假设再测试，不原样套用镜头时长、构图顺序与运动轨迹。未实际观察的数留空，不根据作者宣传语补齐。

## 边界

- 参考只借**方法和气质**，不照搬别人的构图顺序、文案、插画和品牌元素；拆解表里「可学的点」要写成我们自己能复用的规则。
- **参考片只用来拆解学习**：它的画面、配乐、音效和素材一律不能剪进成片。
- 给了参考后，**说清要的效果和约束，不要替模型指定实现库**（除非为了复用必须用某个框架）：参考片的纸张质感可能用 p5.js 做，也可能自己写一个渲染器更贴。
- 优先使用用户自有或已授权的产品事实与品牌素材；不要为了贴近爆款而抹去产品差异。多来源研究也不是拼接复制的许可。

## Git 项目与代码：复用边界

本 Skill 默认**自行设计叙事与画面，使用自有模板或获授权依赖实现**；不把找一个相似宣传片仓库作为制作起点。

| 情形 | 处理 |
|------|------|
| 研究成片、教程、公开方法帖 | 记原始链接、作者、日期和实际看见 / 读到的内容，提炼原则；不下载工程照抄 |
| 正常使用库、API、官方最小示例 | 按官方接口独立实现，核对对应版本许可；引用片段时保留要求的版权 / 许可说明 |
| 用户明确要求复用第三方工程或模板 | 先检查具体版本、文件级许可、NOTICE、依赖与素材；授权允许且范围明确才使用，标为复用 / 改编，不宣称全原创 |
| 公开仓库但无 LICENSE，或许可覆盖不清 | 不复制到交付物；请求权利人授权或另行独立实现。公开、可 fork、注明来源都不等于通用复用许可 |
| MIT / Apache 等代码仓库内带音乐、截图、商标、字体或模型 | 分别核资产权利；代码许可不能自动覆盖所有素材，也不意味着可以复刻整片创意 |

禁止用改变量名、换文案 / Logo / 配色、改镜头顺序或删署名把别人项目包装为原创；不要把第三方代码粘给模型要求“改写得不像”，也不假设 AI 重写自动消除来源义务。合法技术复用不等于盗用，但须如实说明来源、范围与许可。

GitHub 对公开仓库与许可的说明见 `product-video-sources.md` 的 O2；这里是制作风险控制，不替代法律意见。

## 原创与来源记录（并入分镜，不新增审批）

每个外部参考或复用项登记：

| 项目 | 来源 / 作者 / 版本或日期 | 角色与观察层级 | 使用范围 / 许可状态 | 本片如何转译 / 需保留说明 |
|------|--------------------------|----------------|---------------------|---------------------------|
| {参考帖 / 库 / 素材 / 片段} | {原始链接、commit 或文件路径} | {方法参考 / 实际复用；文字 / 静帧 / 视频} | {仅研究 / 获准使用；未知则不纳入成片} | {自行设计点、署名 / LICENSE / NOTICE 位置} |

在关键静帧与交付关各做一次人工对照：是否连同文案、构图、时序、独特转场和资产形成对某一作品的明显复刻。若是，回到本产品事实重设叙事和表达，或走明确授权的改编路线；不靠“相似度百分比”宣布原创。记录只用于本次检查，不能证明未查过的历史代码或所有资产已经完成法律审计。
