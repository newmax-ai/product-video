# 风格预设：视觉系统的起点

在确认点 1 前先给 2–3 个方向及代表性静帧（见 `creative-direction.md`）。预设帮助起步，**不等于换一套颜色就完成设计**。保留品牌真实资产，把母题、构图、密度、空间、材质光影与镜头一起定下来；全片共享一套系统，但允许有目的的明暗、尺度和密度变化。

以下颜色和数值是起点，不替代品牌 token、字体授权与手机可读性检查。光斑、漂浮、噪点和景深都可关闭，不要求背景一直运动。

## P1 浅色渐变科技（ListenHub 式）

适合：AI 生成工具、音频 / 视频 / 图像类、大众 SaaS。

| token | 起点 |
|-------|------|
| 背景 | `#FFFFFF`，可叠少量低对比大光斑（粉 `#F9C6D6` / 紫 `#CFC4F7` / 蓝 `#BFD6FB`，blur 120px+）；不默认全片渐变 |
| 转场底 | `#141418`，只在需要段落对比时使用 |
| 标题 | `#111`，无衬线粗体（Inter / PingFang SC Semibold），强调词用真实品牌色 |
| 卡片 | 白底，圆角 16–20px，阴影 `0 20px 60px rgba(40,30,80,.12)` |
| 深色卡 | `#0E0E12`，表达选中 / 播放状态，不当纯装饰 |
| CTA | 黑色胶囊 + 白字 + 箭头，按品牌实际样式调整 |

- **母题 / 构图**：输入汇聚到一个清晰核心，再扩展成真实成果；操作段偏心聚焦，结果段可铺满，避免每镜头居中字。
- **密度 / 空间**：清爽 UI → 集中结果 → 有序成果阵列；2D 操作为主，2.5D 层级或一段真实 3D 主体亮相作强调。
- **材质 / 光影 / 镜头**：哑光浅色舞台、柔和接触阴影；侧移揭示关系，落定正视 UI。光斑不能盖住字或替代光照。

## P2 暗色 HUD 编辑部（小互式）

适合：资讯、研究、数据、开发者工具，强调可信与专业。

| token | 起点 |
|-------|------|
| 背景 | `#141110` 近黑暖灰，可有局部低对比暖光 |
| 强调色 | 橙红 `#E8562A`；语义允许时次强调薄荷绿 `#7FD8B0` |
| 标题 / 数字 | 白，无衬线；数字可用 Space Grotesk / Söhne 类（核授权） |
| HUD | `品牌 · 栏目 / 章节`，等宽小字，按最小字号规范；`REC` 只在真实录制含义成立时用 |
| 装饰 | 四角直角括号、短线与编号，有信息角色才出现 |
| 原则卡 | 橙 / 米白 `#F3EFE7` / 近黑变化；明确是品牌原则，不是效果证据 |
| CTA | 橙色方角按钮 + 网址 |

- **母题 / 构图**：资料归档、证据逐层核对；编辑网格、强尺度数字和细注释形成秩序，不把小字塞成“科技纹理”。
- **密度 / 空间**：密集来源段之后给结论留空；2D 核实与图表为主，必要时用分层档案解释来源关系。
- **材质 / 光影 / 镜头**：暗色哑光与少量金属边，侧光定义厚度；固定视角读证据，短侧移揭层级，避免无功能 HUD 和发光网格地板。

## P3 暖纸质感艺术（YouMind 式）

适合：创作、学习、写作、设计平台。

| token | 起点 |
|-------|------|
| 背景 | 米白 `#F6F4EF`，可加极淡、有授权或程序化的纸纹 |
| 标题 | 宋体 / 衬线（思源宋体、Noto Serif SC、英文 Tiempos / Playfair，核授权），深墨 `#1C1C1C` |
| 章节 | 「◆ 动词」，或品牌自己的符号 |
| 作品卡 | 真实作品，圆角 8–10px，少量倾斜 −8°～8°，阴影 `0 16px 40px rgba(0,0,0,.14)` |
| UI 面板 | 白卡圆角 12px，细边框 `#E8E4DC` |
| CTA | 黑色胶囊「开始创作 →」 |

- **母题 / 构图**：工作桌、收集夹或编辑画布；作品和批注构成偏心布局，手工感来自关系与材质，不来自随机乱摆。
- **密度 / 空间**：从一张作品到有组织的展览；阅读段平面，作品厚度和陈列层次可用 2.5D / 3D。
- **材质 / 光影 / 镜头**：纸、织物、哑光台面分工，温和侧光与真实接触阴影；横向巡视作品，停下来让人看清，不持续漂浮。

## P4 风景照 + 毛玻璃（Manus 2.0 式）

适合：平台、Agent、大版本发布。数值是参考成片近似起点，不要求照抄其明暗规则。

| token | 起点 |
|-------|------|
| 内容底 | 浅灰 `#F4F4F4`，可加 2–3% 稳定细噪点，不能闪烁 |
| 导航底 | 近黑 `#0B0B0C`，或与内容明确区分的品牌底 |
| 风景底 | 有授权的低饱和自然照片，同组调色；可静止，不强制推近 |
| 标题 | 几何无衬线中等字重（Inter / SF Pro Medium），`#1D1D1F`；风景底上按对比选色 |
| 强调色 | 天蓝 `#3A9BEA` 或真实品牌色，承担导航和重点角色 |
| 玻璃卡 | 白 30–40% 透明 + `backdrop-filter: blur(24px)` + 1px 白 50% 描边，圆角 20px；内容区须保证可读 |
| 设备 / CTA | 简洁圆角外框 + 柔和影子；需要 CTA 时用深色胶囊 |

- **母题 / 构图**：开阔环境中的工作入口，利用远景和清晰主体的尺度对比；不是每帧都漂一个窗口。
- **密度 / 空间**：环境亮相 → 正视 UI → 结果展示，景观只做语境，不冒充真实使用场景。
- **材质 / 光影 / 镜头**：透明边缘和不透明内容面分开；玻璃需要合理厚度、反射与背景关系。照片 + CSS 模糊是 2D / 2.5D，不宣称真实 3D。需要几何遮挡与相机移动再进入 Three.js。

风景照要核授权；AI 氛围图须说明用途并保持统一调色，不能代替真实产品、实物或用户作品证据。

## P5 精密哑光舞台

适合：工具、设计软件、强调系统性与完成度的品牌；真实 3D 可在这里承担主体亮相和界面分层。

| 系统项 | 起点 |
|--------|------|
| 母题 | 一个从闭合到展开的工作台，真实功能按关系出现 |
| 构图 / 密度 | 大主体 + 少量短标题；细节段切正视，成果段阵列展开；主体偏心留出文字区域 |
| 颜色 / 排版 | 暖灰 / 石墨中性色 + 单一品牌强调；无衬线标题，细注释按手机尺寸验读 |
| 材质 | 哑光主体、薄金属边或透明局部各有角色；不要所有表面镜面化 |
| 光影 | 宽主光塑形，低强度补光，接触影建立重量；背景不发光争夺主体 |
| 镜头 | 短侧移 / 适量绕行读出体积 → 落定正视 UI；不连续旋转、甩镜或无目的飞行 |
| 技术边界 | 真实几何 / 灯光 / 遮挡走 `three-workflow.md`；UI 表面来自真实导出，不伪造设备硬件 |

## P6 有序成果展览

适合：创作与生成产品，真实产出多样且视觉质量足够。

| 系统项 | 起点 |
|--------|------|
| 母题 | 内容从工作界面进入可巡视的展览，再回到一个可操作的成果 |
| 构图 / 密度 | 主展品、分组次展品、环境三级；密度增加但中心清楚，关键作品有阅读停留 |
| 颜色 / 排版 | 环境中性，让真实作品自身色彩成为主角；短标题置于独立清晰区域 |
| 材质 | 纸张、画框、薄面板或屏幕按真实内容选择；材质变化不能篡改作品色彩 |
| 光影 | 展品可读优先；阴影和反射帮助定位，景深不糊主作品 |
| 镜头 | 有目标的横向 / 纵深巡视，停在代表作品上，再对齐回真实 UI |
| 技术边界 | 平面陈列用 2D / 2.5D；真实体积、遮挡与移动视角才用 3D；展品数量不是用户量或性能证据 |

## 自定义系统必须记录

- 视觉母题与至少 3 个应用方式；不应用的场合。
- 网格、锚点、主次尺度、密度波形、字体角色与安全区。
- 背景、主色、强调色（默认最多 2 个）、明暗场景的语义。
- 2D / 2.5D / 3D 分工；几何深度、材质角色、光方向和相机规则。
- 产品卡片圆角 / 阴影 / CTA 与真实 UI token；视频舞台和产品内部样式不要混为一谈。
- 动作 / 停留 / 节拍策略；可用装饰、禁用套路、真实资产与授权。

这些约束写进分镜与品牌档案。验收看黑白缩略图、联系表、参考并排和正常速度，不只看 token 表。
