# 截取真实产品的交互状态

产品能导出 DOM 时优先按 `html-ui-rebuild.md`；只有源码时可重建。无法使用这两条路线或涉及非 DOM 内容时，用真实状态截图 / 帧序列作为成片素材；其他情况下可作为对照基准。不要把静态截图的淡变叠影伪装成连续操作。

## 隔离与真实性

1. 默认使用独立用户目录 / 账号的演示实例，不操作用户真实数据库。只有用户明确授权的采集才连接指定真实实例，且不得修改真实记录或触发未授权外部动作。
2. 用产品支持的接口在演示实例准备数据；涉及写库 / IPC 的操作先确认目标实例与副作用。需要点开的交付物必须有真实文件。
3. 需要构造状态时，在独立演示夹具中明确标记“模拟”；模拟成功不能作为真实执行成功、性能或可靠性的证据。
4. 实际执行失败就保留事实；可换已验证案例或只讲交互流程，不把失败记录改成成功。缺登录 / 配置时准备有效演示环境，不通过关闭校验伪造功能可用。
5. 导出前后检查姓名、账号、密钥、头像、文件路径和背景中的敏感内容；演示数据说明写入分镜证据表。

## 采集流程

1. 连接一次 CDP，记录实例、原页面和截图视口；可用 `scripts/cdp.mjs`。
2. 点击、悬停、按下和提示气泡由产品真实渲染。按帧需要记录目标矩形、光标位置、主题和状态到 `meta.json`。
3. 输入用真实输入接口分块推进并捕获。需要连续动画时采足实际中间状态，不用两张静帧假装流畅的菜单动画。
4. 外部动作默认不执行；如果只是演示点击，用明确隔离的模拟事件处理，不依赖“按钮外松开”猜测是否会触发请求。
5. 每段开始清理演示草稿与无关弹层；只操作演示实例。结束后恢复原页面。

## 合成与主题

- 优先聚焦相关组件；需要交代上下文时可以展示整体窗口，但缩小的细字不能承担核心信息。
- 用 DOM 实测边界和圆角，保留真实相对位置。弹层、菜单与组件分开采集时，核对遮挡、阴影和状态一致性。
- DOM 路线可保留产品壁纸；截图拆组件时可使用产品自带纯色主题以获得干净边缘，记录这一采集处理。不能重画成产品不存在的主题。
- 截图倍率按最终显示面积和素材分辨率计算，不固定要求 2× / 3×。独立 webview 的实际像素尺寸另查；高分辨率不等于显示字号够大。
- 推近与裁切可用于聚焦，但要保留操作因果与必要上下文，不能裁断菜单、暴露补丁或假装源图有更高细节。优先捕获足够分辨率，不盲目放大。
- 瞬时状态可按帧切换；有动画的状态捕获真实中间帧或用有依据的重建。避免带文字的截图长时间交叉淡化造成双影。
- 光标按实测坐标运动；涟漪固定在点击位置。系统标题栏等元素以真实捕获为准，不凭印象补画。
- 会轮换的提示内容可在演示夹具里固定；不得遮住关键状态、弹层或错误提示，不能用补丁掩盖能力缺陷。

## 配乐选材

- 首选有授权的成品曲，核实用途及平台版权识别风险。Apple Loops 等素材按当前许可使用，记录来源。
- 编排 loop 时核对速度、调性和段落，统一听感响度；配乐不是强制所有操作吸拍的依据。
- 响度与淡出服从投放约定；无声循环片不额外添加音乐或片尾淡黑。
