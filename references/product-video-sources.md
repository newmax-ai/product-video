## 证据口径

- **官方文档**：只支持其明确的场景；平台广告建议不等于所有产品视频的制作标准。
- **作者文字经验**：通过 NewMax X Search 取得原帖链接和文字摘要；本轮未逐帧观看所附视频，也未独立完成全量原帖存档。作者描述不能标成自己的画面观察。
- **本 Skill 的制作建议**：基于来源与现有流程综合形成的规则、示例和诊断表，不是来源原文或实验结论。

本轮没有取得可靠对照实验来支持普遍最优时长或剪辑公式。没有下载案例视频、第三方 Git 仓库、代码工程或资产，也不根据播放量判定方法优劣。
