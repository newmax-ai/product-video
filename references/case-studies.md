# 参考片逐秒拆解

时间码按 1 秒抽帧和 ffmpeg 场景切点（`scene>0.25`～`0.3`）统计。

| 案例 | 片型 | 时长 | 风格预设 | 最值得学的 |
|------|------|------|---------|-----------|
| A ListenHub | 宣传片 | 30.7s | P1 浅色渐变科技 | hook 让产品「做一次它最擅长的事」；能力镜头全是「输入 → 结果」 |
| B 小互 · Best Blog | 宣传片 | 41.8s | P2 暗色 HUD 编辑部 | HUD 章节标签；把「可信」做成放大镜、图表这类可见证据 |
| C YouMind | 宣传片 | 45s | P3 暖纸质感艺术 | 三个动词串起产品；「01/04」分页；结尾复用品牌镜头 |
| D Manus 2.0 | 发布会长片 | 166.5s | P4 风景照 + 毛玻璃 | 目录滚轮导航；句子长大 / 原地改写；预览窗放大成全屏产出；One More Thing |

A–C 都是 16:9、30fps、纯音乐无旁白（ListenHub 只在开头用自家 TTS 念了一句），画面全部是代码生成的 UI 和排版。

## A. ListenHub（30.7 秒）—— 浅色渐变科技风，节奏最快

**风格**：白底 + 粉/紫/蓝大面积柔和光斑（mesh gradient 缓慢流动）；黑色粗体无衬线标题，强调词用品牌紫；UI 卡片白底大圆角软阴影；logo 段落切到深色背景。

| 时间 | 镜头 | 画面上的字 | 视觉证据 / 动作 |
|------|------|-----------|----------------|
| 0–4s | Hook：产品能力现场演示 | Welcome to **ListenHub**. Let this voice bring your ideas to life. | 顶部小标签「AI 生成的声音 · 实时」；声波条随真实语音跳动；字幕卡拉 OK 式逐词从浅灰变黑，品牌名变紫 |
| 4–7.5s | Logo 揭示 | ListenHub / 任何素材，都能做成音频、图片和视频 | 切深色背景，logo 放大入场，同心圆描边扩散；副标题延后淡入 |
| 7.5–12.5s | 输入 → 输出 | 一条链接，**一期播客** | 白色输入卡：YouTube 链接 + 一句需求 + 「免费生成」按钮；卡片 3D 倾斜，光标点击按钮；卡片翻成深色播放器（标题、双人主播头像、声波、进度条） |
| 12.5–15s | 批量产出 | 写稿、选声、配音，一次完成 | 播放器缩小，四张节目卡片（封面图 + 标题 + 时长）依次飞入成 2×2 |
| 15–20s | 能力参数 | 910 / 12 / 12（官方音色 / 种语言 / 种可克隆语言） | 数字 CountUp（903→910）；三张音色卡轮流「高亮成深色 + 声波 + 逐字字幕」，其他两张变浅 |
| 20–23s | 声音克隆 | 一段录音，复刻你的声音 | 紫色麦克风圆按钮 → 分裂成「你的声音」（黑）和「克隆音色」（紫）两颗 |
| 23–27s | 作品墙 | PPT / 解说视频 / AI 视频（每类一个毛玻璃标签） | 大量真实生成图铺成网格，缓慢平移；每 1–2 秒换一类，中央毛玻璃胶囊标签 + 一行小字说明；右上角小字「先看别人做的 · 都在 ListenHub 完成」 |
| 27–29s | 开发者入口 | 把 ListenHub 接进你自己的流程 | 深色终端窗口里打字 `npx skills add …`，下一行绿色对勾「skills installed · 在 Claude Code 里直接调用」；底部胶囊标签 Agent Skills / CLI / SDK / OpenAPI / MCP |
| 29–30.7s | 数字 + 结尾 | 635,474+ → 643,000+ 件音视频作品；ListenHub / 让想法，成为作品。/ 免费开始创作 → / listenhub.ai | 数字滚动后上移，logo + slogan + 黑色胶囊 CTA + 网址依次出现 |

**可学的点**：hook 直接让产品「做一次它最擅长的事」；所有能力镜头都是「输入 → 结果」；数字镜头和结尾合并，省时间。

## B. 小互 · Best Blog（41.8 秒）—— 暗色 HUD 编辑部风，信息最密

**风格**：近黑背景 + 橙红强调色；顶部一条等宽小字 HUD（`XIAOHU · AI SCOUT / SCANNING`，右上 `REC 00:14` 计时），随章节切换 `/ PIPELINE` `/ VERIFYING` `/ EXPLAIN` `/ ARCHIVE` `/ BROADCAST` `/ END OF REPORT`；标题、数字四角带橙色直角括号「⌜ ⌟」；中间穿插整屏纯色原则卡（橙 / 米白 / 黑）。

| 时间 | 镜头 | 画面上的字 | 视觉证据 / 动作 |
|------|------|-----------|----------------|
| 0–4s | Hook：痛点画面 | 每天，AI 新东西像潮水一样涌来 | 满屏细密的真实文章标题横向滚动，像信息瀑布 |
| 4–5s | 转折 | 我替你**看懂、判断真假** | 标题墙收缩成一行，残留一条细线，中心文字出现 |
| 5–8s | Logo | 小互 BEST BLOG / AI 精华，**讲到你懂**。 | 方形 logo「B」+ 橙色角括号，背景暗橙光晕 |
| 8–13s | 流程 | 每一篇，都走完这四步：01 看资料 / 02 试工具 / 03 判断真假 / 04 讲明白 | 四个带角括号的编号节点，一条橙线从左往右依次点亮 |
| 13–20s | 核实证据 | 每篇标注来源，**核对真伪** | 真实英文原文标题（Anthropic 博客）作底；放大镜圆形透镜滑过，镜内显示中文解读和「来源 · Anthropic」标注 |
| 20–24.5s | 图表 | 把复杂的事，拆成看得懂的图 | 横向条形图逐条长出（ms 数值 + −82% 百分比），右侧大字「3.1×」+ 小字说明；底部一行小字标出数据来源 |
| 24.5–28s | 规模 | No 1 → No 1611 / 篇解读，每天都在更新 | 3D 纵深飞越，成百张真实文章封面从镜头两侧掠过，中央编号滚动 |
| 28–30.5s | 代表作 | 3 天做完 18 个镜头：… | 一张代表作大图卡片推到画面中心 |
| 30.5–36.8s | 原则卡 ×4 | 真实为底 / 讲透为骨 / 人话为形 / 朋友感为声 | 每张约 1.5 秒，整屏换底色，大字 + 一行解释；左下「PRINCIPLE 01 / 04」 |
| 36.8–38s | 多语言 | AI, distilled & clear. / AI の要点を、わかるまで。 | 顶部「中 / EN / 日」切换器，选中项变橙，下面标题跟着换语言 |
| 38–40s | 播客 | 小互 · Best Blog 播客 / **159** 期，用耳朵读解读 | 声波条，橙色进度从左往右走；下方订阅渠道胶囊（邮件 / RSS / 播客 / Telegram） |
| 40–41.8s | 结尾 | 小互 · AI 解读站 / AI 精华，讲到你懂。/ 已核对来源 · 讲透不注水 · 中英日同步更新 / 免费注册 · 订阅新解读 / best.xiaohu.ai | App 图标式 logo，文字分三行依次淡入，橙色 CTA 按钮 + 网址 |

**可学的点**：HUD 章节标签让观众始终知道「现在在讲哪一段」；用放大镜、图表把「可信」这种抽象卖点做成可见的证据；原则卡用整屏换色制造节奏重音。

## C. YouMind（45 秒）—— 暖纸质感艺术风，节奏最从容

**风格**：米白纸感背景；中文标题用宋体/衬线（文艺、创作者感）；四周漂浮着微微倾斜、带阴影的真实作品卡片（海报、杂志封面、剧照），缓慢漂移；章节用「◆ 动词」；UI 截图左图右面板，圆角白卡。切点非常规整，基本 5–6 秒一段。

| 时间 | 镜头 | 画面上的字 | 视觉证据 / 动作 |
|------|------|-----------|----------------|
| 0–5s | Hook：情绪问题 | 想创作的念头，在心里转了多久？ | 一张电影感插画：夜晚窗前的剪影 + 空白画架（唯一一张氛围图）；字分两行依次淡入 |
| 5–9s | 品牌 + slogan | YouMind / 大胆创作，不止于学 / 你的 AI 工作室，将灵感变成作品。 | 四周作品卡片从画外漂入；标题逐词模糊淡入 |
| 9–11s | 章节 1 | ◆ 收藏 / 文章、视频、播客和笔记，收在一处 | 画面清空再换一组漂浮卡片；副标题逐字出现 |
| 11–15s | 功能演示 1 | 01 收藏你的灵感 | 左侧氛围插画（捕蝶网），右侧「灵感收集」面板里卡片逐张落入，计数从 3 项涨到 5 项 |
| 15–17s | 章节 2 | ◆ 思考 / 与 AI 一起提问、串联想法 | 同上 |
| 17–20s | 功能演示 2 | 02 形成你的见解 | 左侧插画（棱镜分光），右侧对话面板：用户提问 → AI 列出两条观点 |
| 20–22s | 章节 3 | ◆ 创作 / 将所学化为文章、幻灯片、图像、视频 | 同上 |
| 22–26s | 功能演示 3 | 创作你的作品 | 居中输入框里打出「把这些见解，做成一套幻灯片」，下面一排类型标签，光标点中「幻灯片」 |
| 26–33s | 产出类型 ×4 | 01/04 幻灯片 · 02/04 网页 · 03/04 图像 · 04/04 视频 | 左侧大字 + 分页指示条，右侧真实产出大图斜切入场，每类约 1.5–2 秒 |
| 33–35s | 作品墙 | 用 YouMind 创作 / 来自创作者的真实作品 | 大量作品以 3D 倾斜平面铺满，镜头缓慢平移 |
| 35–40s | 用户证言 ×3 | Marco（YouTube 视频博主）「从选题到脚本、分镜、封面，YouMind 帮我在一个对话里全部搞定。」…… | 左照片右文字，姓名、身份、引语依次出现 |
| 40–42s | 里程碑 | YouMind 里程碑：705K+ → 710K+ 创作者 / 5M+ 作品 / 62+ → 70+ 国家和地区 / 20K+ → 31K+ 技能 | 四组数字并排 CountUp |
| 42–45s | 结尾（呼应开场品牌镜头） | 大胆创作，不止于学 / 开始创作 → / YouMind youmind.com | 复用 5–9s 的漂浮卡片构图，slogan 重打一次，黑色胶囊 CTA |

**可学的点**：三个动词串起整个产品（收藏 → 思考 → 创作），每个动词「章节卡 + 演示」两拍；「01/04」分页让观众预期剩余长度；结尾整体复用品牌镜头，完成首尾呼应。

> 注意：C 的用户证言是否真实无法从视频判断。做自家片子时只用真实用户证言，没有就删掉这一段。

## A–C 三支宣传片的共性

| 维度 | 共性 |
|------|------|
| 时长 | 30–45 秒，镜头 10–20 个 |
| 声音 | 纯 BGM，不配音；需要「声音」时让产品自己发声 |
| 开场 | 0–4 秒 hook（能力演示 / 痛点 / 问题），4–8 秒内出 logo + slogan |
| 中段 | 3–4 个能力，每个 = 一句标题 + 一个 UI 证据 |
| 规模证明 | 作品墙 + 大数字 CountUp，数字会「再涨一次」 |
| 结尾 | logo + slogan + 胶囊 CTA + 网址，停 2–3 秒以上，呼应开场 |
| 文字动画 | 逐词模糊淡入（blur + opacity + 轻微上移）是三支片子的主力入场 |
| 卡片 | 大圆角 + 软阴影 + 轻微 3D 倾斜 + 缓慢漂浮 |
